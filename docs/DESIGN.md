# DESIGN.md · 灯塔 Lighthouse 作品介绍

> 走**通用设计原则**（未命中学术 / 咨询 / 政务红金三类预设分支）。
> 视觉来源：应用自身的 UI 令牌（`common/Theme.ets` / `resources/*/element/color.json`），
> 目的是让 PPT、实机截图、演示视频三者看起来是同一件东西。

## 1. 画布与全局母版

- **画布**：1280 × 720 px（16:9）
- **页面 padding**：左右 72px，上 26px，下 24px
- **A · 标题块**：y 26–130px（高 104）。主标题 34px bold，左对齐；右上角可放**页码组**，不放装饰图
- **B · 内容区**：y 130–648px（高 518 可用）
- **C · 页脚条**：y 648–696px（高 48）。左侧「灯塔 Lighthouse · 秋招数据作战台」14px 灰字；右侧页码 `NN / 14`
- 封面 / 章节扉页 / 结束页**省略 C 区**，采用自定义版式（§1 允许）
- 全篇 L3 徽标固定在**页脚条最左**（`assets/mark.png`，40×40），位置逐页一致

## 3. 字体系统

两套字体家族：**思源黑体**（正文/标题）+ **JetBrains Mono**（数字、单位、Kit 名、页码）。

| 层级 | 字号 | 字重 | 行高 | 字距 | 字体 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 76px | bold | 1.15 | 2px | 思源黑体 | 仅 P01 |
| 章节大字 | 64px | bold | 1.1 | 1px | 思源黑体 | P03/06/10/12 |
| 结束页金句 | 46px | bold | 1.3 | 0.5px | 思源黑体 | P14 |
| **巨型数据锚点** | **104px** | **bold** | **1.0** | **-1px** | **JetBrains Mono** | **P05；全篇 ≥ 1 个/页** |
| 页面主标题（A 区） | 34px | bold | 1.3 | 0 | 思源黑体 | 内容页固定 |
| 副标题 / 卡片小标题 | 24px | 600 | 1.4 | 0 | 思源黑体 | 卡片头 |
| 正文 | 21px | normal | 1.62 | 0 | 思源黑体 | 段落 |
| 引文 / 判断句 | 22px | normal | 1.55 | 0 | 思源黑体（左侧 3px 蓝竖线） | 「」判断句 |
| 脚注 / 页码 / 来源 | 14px | normal | 1.4 | 0 | JetBrains Mono | C 区、数据来源 |

- 巨型数字必须有别于正文：**字重 bold + 等宽字体**，与 14px 脚注形成 7.4 倍尺度跳跃
- 数字后跟单位用 28px、次文本色，不进入巨型字号

## 4. 信息密度门禁

| 页面类型 | 元素数 | 正文字数下限 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- |
| 封面 P01 | 主标题 + 副标 + 主视觉 + 署名 | 60 | ≥ 35% |
| 目录 P02 | 4 条 + 引导句 | 140 | — |
| 章节扉页 ×4 | 大字 + 一句小标 | 30 | ≥ 40% |
| 内容页 · 双栏 | 标题 + 两栏 | ≥ 260 | ≥ 30% |
| 内容页 · 图 + 文 | 标题 + 大图 + 卡组 | ≥ 200 | ≥ 40% |

| 结束页 P14 | 金句 + 落款 | 30 | — |

默认留白上限 35%；Hero 页允许 40–50%（围绕焦点元素，不做均匀稀薄）。
容器填充率 ≥ 85%，卡片尾部元素（来源条 / 标签条）一律 `marginTop: 'auto'` 钉底。

## 5. 配图系统

**本项目刻意采用"实机截图为主、生图只做封面"的配图策略。**
理由：这是一份参赛作品介绍，评委要判断的是"这东西真做出来了吗"——一张实机截图的说服力远高于一张氛围插画。风格统一性由同一个 UI 令牌保证。

| 等级 | 元素 | 位置 | 最小尺寸 | 来源 |
| :--- | :--- | :--- | :--- | :--- |
| L1 | `cover_bg.png` | P01 全幅 | 1280×720 | **ImageGen**（唯一生图） |
| L1 | `card_desktop.png` 桌面卡片实拍 | P08 左侧 58% | 约 1216×750 | 模拟器实拍（深色主题） |
| L1 | `radar.png` 能力雷达实拍 | P09 上部 | 约 1120×330 | 模拟器实拍（深色主题） |
| L1 | 三组巨型数字 | P05 | ≥ 96px | 文本 + 等宽字体 |
| L2 | 能力矩阵表 | P11 宽侧 | 760×430 | 手工表格（Box 行） |
| L3 | 灯塔徽标 | 全篇页脚条最左 | 26×26 | **内联 Box 徽标**（蓝底 + 「灯」字），不用位图 |

**实机截图的取景规范**：只保留手机屏幕内容区，**裁掉模拟器外框**（避免"这是模拟器"削弱可信度）；圆角 18px；描边 `1px rgba(74,158,255,0.35)`；投影 `0 10px 30px rgba(0,0,0,0.45)`。全篇截图统一同一取景与同一描边。

生图规则：**全篇只生 1 张图**（封面），风格词固定为「deep dark navy, volumetric light beam, minimal, cinematic, no text」，避免与实机截图抢注意力。

## 7. 一致性自检清单（逐页提交前核对）

1. A/B/C 三区位置逐页一致（扉页/封面/结束页除外）
2. 主标题字号 34px、位置 (72, 40) 固定
3. 页码 `NN / 14` 固定在右下 (1160, 662)
4. L3 徽标固定在左下 (72, 660)
5. 全篇只用 4 个 hex + 白系透明度
6. 每页 ≥ 1 个视觉锚点（≥ 44px 元素或 ≥ 40% B 区面积的图）
7. 相邻页版式不重复；无等宽卡片横排
8. Hero 页留白 40–50% 且围绕焦点；Supporting 页留白 ≤ 35%
9. 含数字的页必须「数据 + 判断」两段式
10. 实机截图统一取景、同描边、同圆角、同投影
