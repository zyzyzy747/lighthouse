# STORY.md · 灯塔 Lighthouse 作品介绍

## ① 用户意图对齐

**目标受众**：2026 第二届「光谷杯」鸿蒙生态创新大赛初赛评委（线上材料评审）。评委构成里既有鸿蒙技术专家，也有政府领导与产业/投资侧评委——技术深度与政策叙事必须同时成立。

**核心目标**：讲完之后，评委要记住三件事——
1. 「桌面服务卡片是主入口」——这是鸿蒙原生最直接的证据；
2. 「能力雷达把弥散焦虑收敛成一张补强清单」——这是市面上没人做过的创新点；
3. 「一屏三形态：手机随手记 / 平板看全局 / 折叠屏作战」——这是一多部署的真实价值。
最终诉求：在创新性 50 分上拿高分，并让「前景评估」20 分有政策抓手可依。

**PPT 长度**：14 页（章节扉页 4 页 + 封面/目录/结束 3 页 + 内容 7 页）。Hero 页 4 页（28.6%）。

**视觉调性**：深海科技 · 单色系统 · 数据驱动 · 克制。与应用 UI 同源（深海蓝底 + 主蓝 + 琥珀强调），让 PPT、实机截图、演示视频三者视觉一致——评委在视频里看到的界面必须和 PPT 上是同一套东西。

**内容边界**：
- **必讲**：三大痛点、真实数据与政策抓手、桌面卡片作为主入口、能力雷达的算法口径、一多三形态、鸿蒙能力矩阵、光谷产业结合。
- **不讲**：12 天排期表、风险清单、答辩预演四问、实况窗的取舍过程（这些是内部工作文档的内容，放在 PPT 里只稀释重点）。
- **禁碰**：未在工程里验证过的 API 名称；把演示数据说成调研结论；任何无法核验的数字。
